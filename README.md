# Expense-Manager-Premium
Expense Master Premium is a modern, feature-rich desktop application designed to simplify personal finance management. Built with Electron.js, HTML, CSS, and JavaScript, this application offers a secure, offline-first approach to tracking daily expenses and monthly incomes.

**Expense Master Premium** is a modern, offline-first desktop application designed to help you easily track your personal finances, manage daily expenses, and monitor your monthly income through a premium dark-themed interface.

Developed by **KreativeLabs**.

---

## ✨ Key Features

* 📊 **Interactive Dashboard:** Get a quick overview of your total income, expenses, and current net balance. Includes dynamic Doughnut charts for visual analytics.
* 📅 **Advanced Filtering:** Seamlessly track finances by specific days, months, or years.
* 📈 **Income & Expense Tracking:** Easily add, categorize, and delete your daily financial transactions.
* 📄 **Professional PDF Reports:** One-click generation of detailed monthly reports separating Incomes and Expenses.
* 🔒 **Secure & Offline-First:** 100% privacy. All your financial data is stored securely on your local machine. No internet connection required!
* 🎨 **Premium UI/UX:** A sleek, highly responsive, and eye-friendly dark interface crafted for the best user experience.

---

## 💻 Tech Stack

This application is built using modern web technologies packaged into a standalone desktop application:
* **Framework:** [Electron.js](https://www.electronjs.org/)
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Data Visualization:** [Chart.js](https://www.chartjs.org/)
* **PDF Generation:** [jsPDF](https://parall.ax/products/jspdf) & jsPDF-AutoTable
* **Date Picker:** [Flatpickr](https://flatpickr.js.org/)

## 📥 Download & Installation

You don't need to build the project from source! Simply download the installer to get started:

1. Go to the [Releases](../../releases/latest) page.
2. Download the **`Expense Master Premium Setup 1.0.0.exe`** file from the Assets section.
3. Double-click the downloaded `.exe` file.
4. Follow the simple installation wizard.
5. Launch the app from your Desktop or Start Menu and take control of your finances!
